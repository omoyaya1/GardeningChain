# GardeningChain

A decentralized organic gardening and cultivation reward system that gamifies sustainable farming and horticultural expertise on Stacks blockchain.

## Features

- Planting season management with growing period and crop type tracking
- Yield-based reward system with organic level bonuses
- Seed preservation mechanics with time-based bonuses
- Community garden establishment for advanced gardeners
- Gardening workshop teaching system for education
- Comprehensive gardening statistics and analytics

## Smart Contract Functions

### Public Functions
- `start-planting-season` - Begin planting with growing period and crop type
- `complete-harvest` - Complete harvest and earn rewards based on yield quality
- `claim-gardening-rewards` - Claim accumulated gardening tokens
- `preserve-seeds` - Preserve seeds for enhanced rewards
- `release-preserved-seeds` - Release seeds with time-based bonuses
- `establish-community-garden` - Create community gardens for bonus rewards
- `teach-gardening-workshop` - Teach workshops for education bonuses

### Read-Only Functions
- `get-gardening-activity-count` - Get total gardening activities for user
- `get-gardening-token-balance` - Get current token balance
- `get-organic-level` - Get current organic mastery level
- `get-harvest-count` - Get number of successful harvests
- `get-preserved-seeds` - Get current preserved seeds amount
- `get-cultivation-mastery` - Get cultivation mastery level
- `get-garden-stats` - Get platform-wide gardening statistics
- `calculate-gardening-reward` - Calculate potential gardening rewards

## Gardening Mechanics
- Growing period affects cultivation time requirements
- Yield quality (0-100) provides bonus rewards
- Seed preservation adds time-based reward multipliers
- Community gardens unlock at higher organic levels
- Early seed release incurs penalties

## Usage

Deploy the contract to create a gamified gardening ecosystem where gardeners can earn rewards for sustainable cultivation, community building, and knowledge sharing.
